# เอกสารภาษาไทย

> เอกสารฉบับนี้เป็นฉบับภาษาไทยสำหรับการอ่านและสื่อสารภายใน โดยเอกสารภาษาอังกฤษต้นฉบับใน repository เป็น source of truth

ชุดเอกสารนี้สรุปและแปลสาระสำคัญของเอกสารสถานะ โครงสร้าง ระบบความปลอดภัย และการยอมรับ M1 เพื่อให้ทีมอ่านร่วมกันได้สะดวกขึ้น ไม่ได้แทนที่เอกสารภาษาอังกฤษ และไม่ครอบคลุมเอกสารประวัติทั้งหมด
